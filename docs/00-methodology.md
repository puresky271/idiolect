# 方法总纲：让 AI 说话像角色，并且能证明它变像了

> 讲什么：为什么通用模型演角色会稳定跑偏，以及「把像不像变成可测量的量」的完整闭环——四条不变量、四层落地形态、证据分级。 ｜ 前置：无，这是第一篇。

## 1. 问题

拿一个通用大模型扮演角色，你不用做任何事就能得到一个「像那么回事」的回复。问题在于它稳定地滑向同一个方向：

- **变长**。同一个场景，原作里角色说 6 个字，模型写 3 段共 380 字。
- **共情模板**。「你的感受我完全能理解」「先深呼吸」「你已经很不容易了」，换个角色名字照样成立。
- **收束升华**。结尾补一句「不管怎样，我会陪着你」。
- **元叙述**。把自己的写作依据说出来（「按我的台词长度中位数……」），或者干脆自称 AI。

这四种偏差都不需要模型出错，它们是 RLHF 训练目标的正常产物。角色区分度就死在这里：如果乐奈和素世都产出同一段安慰，那这两个角色没有区别。

所以任务不是「写一个更好的角色 prompt」。任务是：**把「像不像」变成可检验的量，然后在这个量上迭代。**

## 2. 总纲

不做 fine-tuning。系统靠基础设施、记忆、上下文和 prompt。这条选择决定了整套方法的形状：模型参数是常量，那么唯一能动的就是**进 prompt 的文本**，以及**出 prompt 的文本**（后处理）。于是全部工作分成两半：

```text
原作台词 ──蒸馏──> 可检验的特征 ──落地──> system prompt ──生成──> 回复
                      │                                        │
                      └────────── 同一个参照系 ────────────────┘
```

蒸馏与评测必须共用同一个参照系，否则数字没有意义。参照系的定义只有一条：

> **同角色、同场景的原作台词分布。**

**目录**：[1 问题](#1-问题) ｜ [2 总纲](#2-总纲) ｜ [3 闭环](#3-闭环) ｜ [4 四条不变量](#4-四条不变量) ｜ [5 落地形态：四层](#5-落地形态四层) ｜ [6 证据分级](#6-证据分级) ｜ [7 已知残余](#7-已知残余) ｜ [8 仓库导览](#8-仓库导览)

不是「人类说话的一般统计」，不是「这个角色的全部台词」，也不是「别的角色在同一场景的表现」。乐奈在「被表白」场景里说 7 个字，素世在同一场景说 17 个字，用全局中位数约束她们两个都会错。

## 3. 闭环

一轮迭代有七个动作，顺序不能换：

1. **抓语料**。原作台词入库，切成 train / test。test 留出来做验证，不参与蒸馏（见 `docs/02-corpus.md`）。
2. **蒸馏**。从 train 里算出五类特征：场景分类、每场景长度目标、句式结构与口癖、物品/话题词表、称呼（见 `docs/03-features.md`）。
3. **落地**。把特征写进 prompt 的对应层，措辞受一套书写规范约束（下一节）。
4. **探针**。固定夹具、固定参数、跑 N 次，拿到分布而不是一条样本。夹具与参数见 `docs/05-tooling.md`。
5. **评分**。分布级指标（`scene_distill`）+ 机械门禁（重复率、逐字复述审计、触发矩阵）。
6. **对照**。把模型回复和原作同场景台词并排读，写出改进点。这一步由 `scene_feedback` 生成对照页，但**结论由人下**。
7. **归因**。改动是落在哪一层、哪一句话上，导致了分数的变化。归不到具体句子上的改动，不许合入。

## 4. 四条不变量

这四条是被违反过、并且每次违反都付出了代价的规矩。它们比任何具体指标都重要。

### 4.1 长度偏差只用来找嫌疑，不定罪

长度是最容易算的量，也是最容易误判的量。灯在「被安慰」场景里输出 50 字，参照中位 10 字：偏差 5 倍。但直接照这个数字压长度会毁掉角色，因为灯的 12 点省略号（`············`）本身就是内容，它计入字数。压掉它，灯就不再是灯。

规矩：长度与句数偏差**只负责把场景挑出来**，判定必须读回复。「这条偏长」不是结论，「这条偏长是因为把对方的话补完整了」才是结论。

### 4.2 角色可见的文本里不许有元叙述

「语料」「实测」「中位」「p90」「基线」「lift」「频次」「统计」这类词出现在 system prompt 里，模型有概率把它们复述出来，或者顺着这个思路把自己当成一个被评估的系统。禁词表在 `tools/gates/voice_meta_gate.py`。

这条规矩的价值等于门禁的覆盖面。这条门禁曾经只扫角色包的 `voice.py`，于是 `style_target` 的块标题「实测台词基线」在每个人的 prompt 里躺了很久没人发现（`实测` 就在禁词表里）。现在的门禁扫四个面：canon 长档案、voice manifest、说话尺度块、turn_logic 渲染结果。

### 4.3 写进 prompt 的正文里不许有能整句照抄的例句

早期版本在注入正文里写了正例台词，方便模型模仿。实测后果（旧批次记录，产物未随仓库发布）：生产臂 22%~27% 的回复逐字复述了正文里的句子，最长公共子串 22 字。模型把「例句」当成了「台词库」。

现行规范（`tools/gates/_gen_scene_check.py` 的机械门禁）：

- 只给**字数上限 + 句数 + 结构描述 + 口癖长度的起手**（≤4 字）；
- canon 里的原话一律改成「从你自己的档案里取」，不在注入正文里复述；
- 正例、反例、口癖示例都要能在门禁里被识别并跳过，所以书写时用固定的标记词。

改写后逐字复述率降到 **1%、最长公共子串 3 字**（`repo_standalone` 批次，`tools/score/_copy_audit.py` 可复现；抄的那 3 个字是口癖「诶……」，不是例句）。

### 4.4 样本量不够就报「无结论」

单臂每格 6 条时，中位数的摆动可以超过效应本身。实测过：同一场景、同一个 prompt，乐奈的蒸馏分从 0.551 摆到 0.350。按这个数据宣布「改动有效」是自欺。

规矩：单臂 n=6 的逐格对比只能当线索；要下结论必须池化多臂（多个夹具/多批次的同向变化做符号检验）。功效估算在 `tools/score/power_calc.py`。里面记着一个实例：乐奈某维度单条标准差 0.382，96 条/臂只够把 95% 区间压到 ±7.5 个百分点，而观测到的前后差是 5.1 个百分点（z = 0.93）。按这个效应量要在同一维度上达到显著，量级是**几百条/臂**——具体数取决于口径：单样本公式给 ~224 条/臂，两独立样本等组、50% 功效约 450 条/臂（`power_calc.py` 的 docstring 里写明了，引用时别混用）。样本量不够时，池化是唯一还能下结论的做法。

## 5. 落地形态：四层

蒸馏出来的东西最后落在四个层里，顺序固定，因为稳定前缀在前可以让缓存命中，动态块在后不会污染前缀：

| 层 | 内容 | 变化频率 |
|---|---|---|
| `canon` | 这个角色是谁，长档案 | 静态 |
| `voice` | 语气 manifest：句式、口癖、关系差异、反模板化硬约束 | 静态 |
| `style_target` | 说话尺度：字数、句数、句末、自称的可检验数字 | 每轮（命中场景时换成本场景的数字） |
| `turn_logic` | 本轮的场景/主题指引 | 每轮（命中才注入） |

前三层是「这个人一般怎么说话」，第四层是「这一轮她该做什么」。装配代码在 `idiolect/assemble.py`，逐层的字符数可以用 `tools/gates/dump_prompt.py` 打出来。

后处理是第四条落地路径，但它与 prompt 不同：**它会删字**。所以风格改写（删冗余起手）放在 API 层，无损清洗（标点归一）才放进 `clean_reply`。这个边界见 `idiolect/characters/rana/api.py` 的 `post_reply_voice_check`。

## 6. 证据分级

讨论改动效果时，分清三档证据，不要把低档当高档用：

| 档 | 来源 | 能证明什么 |
|---|---|---|
| 机械门禁 | 触发矩阵、逐字复述审计、禁词扫描 | 「某条规则被违反了」。可复现，可进 CI |
| 分布级评分 | 多夹具 × N 次生成 | 「改动方向上更接近参照系」。需要样本量，需要池化 |
| 单条读稿 | 人工读回复 | 只能提出归因假设（「它把对方的话补完整了」），不能定量 |

`scene_distill` 的分数是相对量，只用于同批次内的 before/after 比较，不能跨批次当绝对值用。

## 7. 已知残余

方法论的可信度取决于它敢写下多少失败记录。当前明确没解决的：

- **零样本用词的代价**。禁用整句例句之后，长度贴合度从 0.512 掉到 0.461（旧批次记录，产物未随仓库发布）。这条代价是自愿接受的（复述率 22% 比长度偏差更伤角色），但它确实存在。
- **立希起手句式的过度矫正**。原作里她 39% 的回合以名词直出，当前臂升到 62%（`tools/score/_noun_initial.py <批次名>` 会把原作基线与当前臂并排打出），方向反了。这类「按规则改、改过头」的坑，靠具名锚点（读角色档案里的原话）而不是通用规则来防。
- **灯的省略号记账**。参照系默认剔除沉默回合，但灯的 12 点停顿是内容。silent turn 的处理目前两头不讨好。
- **探针夹具的可测性**。「你刚才那句什么意思」这类场景需要上文有可指代的那句话，占位夹具没有上文，于是这个场景的分数不可读。
- **单个角色的后处理规则覆盖率**。乐奈的冗余起手清洗只覆盖一种形态，剩余的 33% 是语料里确有的短确认形式，不该动。
